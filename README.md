# Wind Turbine Performance Dashboard

## Project Overview

This project analyzes wind turbine performance, faults, maintenance activities, and downtime using Power BI and SQL Server.

## Tools Used

- Power BI
- SQL Server
- DAX
- Power Query
- Data Modeling

## Dashboard Pages

### Executive Overview
- Total Energy Produced
- Average Availability
- Wind Speed Analysis

### Fault Analysis
- Fault Severity Analysis
- Fault Code Analysis
- Country-wise Fault Distribution

### Maintenance Analysis
- Maintenance Cost Analysis
- Preventive vs Corrective Maintenance

### Downtime Analysis
- Downtime Hours
- Downtime Reasons
- Turbine Downtime Ranking

## Data Model

Star Schema:
- DimDate
- DimTurbines
- FactProduction
- FactFaults
- FactMaintenance
- FactDowntime
